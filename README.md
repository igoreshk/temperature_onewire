# 📡 Датчик температуры DS18B20 (DS1820) — подключение к Arduino по 1-Wire

## 📖 Вводная часть

**DS1820** — цифровой датчик температуры, работающий по шине **1-Wire**.
Современный и наиболее распространённый аналог — **DS18B20**.

**Ключевые особенности:**

- Диапазон измерений: **−55…+125 °C**
- Точность: **±0.5 °C** в диапазоне −10…+85 °C
- Разрешение: **9…12 бит** (шаг 0.5…0.0625 °C)
- Напряжение питания: **3.0…5.5 В**
- Каждый датчик имеет **уникальный 64-битный адрес** — можно вешать много датчиков на один пин

## 🔌 Схема последовательного подключения

### Вариант 1: Один датчик

```text
                +5V ●──────────┬──────────────┐
                               │              │
                              [R] 4.7kΩ       │
                               │              │
   Arduino Pin 2 ●─────────────┴──────┬───────┤
                                     │       │
                                     │   ┌───┴────┐
                                     │   │  VDD   │
                                     │   │  DQ    │
                                     │   │  GND   │
                                     │   └────────┘
                                     │   DS18B20
   Arduino GND ●─────────────────────┘
```

### Вариант 2: Несколько датчиков на одной шине

```text
   Arduino          DS18B20 #1        DS18B20 #2        DS18B20 #3
   ┌──────┐         ┌────────┐        ┌────────┐        ┌────────┐
   │  5V ─┼────┬────┤ VDD    ├────────┤ VDD    ├────────┤ VDD    │
   │ GND ─┼────┼────┤ GND    ├────────┤ GND    ├────────┤ GND    │
   │  D2 ─┼─[4.7k]──┤ DQ     ├────────┤ DQ     ├────────┤ DQ     │
   └──────┘         └────────┘        └────────┘        └────────┘
```

### Распиновка DS18B20 (корпус TO-92, вид снизу)

```text
      ┌─────┐
      │ 1 2 3│
      └──┴─┴─┘
       │  │  │
      GND DQ VDD
```

| Контакт | Название  | Цвет провода (типовой) |
|---------|-----------|------------------------|
| 1       | GND       | Чёрный                 |
| 2       | DQ (Data) | Жёлтый / Синий         |
| 3       | VDD (+5V) | Красный                |

## ⚙️ Технические характеристики DS18B20

| Параметр                     | Значение                              |
|------------------------------|---------------------------------------|
| Диапазон измерений           | −55…+125 °C                           |
| Точность (−10…+85 °C)        | ±0.5 °C                               |
| Разрешение                   | 9…12 бит (0.5…0.0625 °C)              |
| Напряжение питания           | 3.0…5.5 В                             |
| Интерфейс                    | 1-Wire                                |
| Время преобразования         | до 750 мс (12 бит)                    |
| Кол-во датчиков на шине      | практически неограничено              |

## 🔧 Полезные советы

- Резистор подтяжки **4.7 кΩ** обязателен между **DQ** и **VDD** — без него датчик не работает.
- Длина линии — **до 100 м** при использовании экранированного кабеля.
- **Паразитное питание** (2 провода) требует MOSFET для сильной подтяжки при преобразовании.
- Каждый DS18B20 имеет **уникальный 64-битный адрес** — можно вешать много датчиков на один пин.
- При нескольких датчиках используйте `sensors.setResolution()` для каждого отдельно.
