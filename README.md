Данное руководство описывает подключение и чтение температуры с цифрового датчика DS1820 (DS18B20) с помощью микроконтроллера Arduino по протоколу 1-Wire.

Материал рассчитан на:
начинающих радиолюбителей и ардуинщиков;
студентов, выполняющих лабораторные работы;
инженеров, которым нужно быстро собрать узел измерения температуры.

📌 Что такое DS1820 / DS18B20
DS1820 — это цифровой датчик температуры, работающий по шине 1-Wire. Его современный и наиболее распространённый аналог — DS18B20. Датчик выдаёт температуру сразу в цифровом виде (без АЦП), что упрощает подключение и повышает помехоустойчивость.

Ключевые особенности:
Измеряет температуру в диапазоне −55…+125 °C;
Точность ±0.5 °C в диапазоне −10…+85 °C;
Программируемое разрешение 9…12 бит (шаг от 0.5 до 0.0625 °C);
Каждый датчик имеет уникальный 64-битный адрес — можно подключать множество датчиков к одному пину;
Питание 3.0…5.5 В;
Возможны два режима питания: внешнее (3 провода) и паразитное (2 провода).

🔌 Почему 1-Wire
Протокол 1-Wire (разработан Dallas Semiconductor, сейчас — Maxim Integrated) позволяет передавать данные и питание по одному проводу (плюс общий GND). Это даёт:
минимум проводов при монтаже;
возможность подключать до десятков датчиков на одну линию;
длина линии — до 100 метров при использовании экранированного кабеля и правильной подтяжки.

🔧 Полезные советы
Резистор подтяжки 4.7 кΩ обязателен между DQ и VDD — без него датчик не работает.
Длина линии — до 100 м при использовании экранированного кабеля.
Паразитное питание (2 провода) требует MOSFET для сильной подтяжки при преобразовании.
Каждый DS18B20 имеет уникальный 64-битный адрес — можно вешать много датчиков на один пин.
При нескольких датчиках используйте sensors.setResolution() для каждого отдельно.
